## 1. Структура игры и экраны

```
Главный экран («сериалы»)
 ├─ 🛰 Last Signal      → список эпизодов → эпизод
 ├─ 🕵 Case Files       → список дел      → эпизод
 ├─ 🏡 Fresh Start      → список глав     → эпизод
 ├─ 📓 Блокнот (общий словарь, повторение)
 └─ 👤 Профиль (уровень, серия, статистика, настройки)
```

**Главный экран:** три большие карточки-«постера» с живыми 3D-превью. На каждой: название, прогресс («Эпизод 4 из 10»), бейдж «Новый эпизод» и бейдж «Продолжить». Сверху серия дней 🔥 и счётчик «сегодня: 0/1 эпизод».

**Экран эпизода:** 3D-сцена на весь экран, внизу панель диалога, сверху тонкая полоса прогресса эпизода и кнопка блокнота.

**Экран итога эпизода** (после каждого):
- новые слова и фразы эпизода (5–8);
- «понял без перевода: 78%»;
- серия дней;
- тизер следующего эпизода с клиффхэнгером.

## 2. Первый запуск и уровень

1. **Интро на 30 секунд:** три постера, «Choose your story». Тест уровня не нужен.
2. **Первая сцена любой истории** написана так, что первые 4–5 реплик идут по нарастающей: A1 → A2 → B1. Игра смотрит, где игрок начал нажимать перевод, и ставит стартовый уровень.
3. **Уровень можно поменять** в профиле вручную: Easy (A1) / Medium (A2) / Hard (B1).

**Автоподстройка дальше:**
- игра считает долю реплик, прочитанных без перевода, за последние 2 эпизода;
- больше 85% — предлагает «Попробуем сложнее?»;
- меньше 50% — тихо упрощает;
- уровень не понижается без ведома игрока: показывается мягкая плашка.

## 3. Эпизод: из чего состоит

Один эпизод = 10–15 минут = **5–7 «битов»**. Все истории используют одни и те же типы битов.

| Бит | Что происходит | Пример |
|---|---|---|
| **Recap** | «Previously on…» — 2–3 кадра с прошлым эпизодом | Голос с рации: «Yesterday you fixed the radio…» |
| **Dialogue** | Разговор с выбором реплик | Допрос свидетеля |
| **Explore** | Осмотр 3D-сцены: тап по предметам, записки, экраны | Осмотр места преступления |
| **Task** | Задача, которая требует понимания текста | Починить генератор по инструкции |
| **Recall** | Персонаж вспоминает прошлое слово в сюжете | «What was the word on the door? The one that means "danger"?» |
| **Choice** | Важный выбор с последствиями | Кому поверить |
| **Cliffhanger** | Интрига, конец эпизода | Новый голос в эфире |

**Шаблон эпизода:**
`Recap → Dialogue → Explore/Task → Dialogue (+Recall) → Choice → Cliffhanger`

**Слова в эпизоде:**
- **5–8 новых** — встроены в ключевые реплики, без них не пройти;
- **8–15 повторений** — подставляются автоматически (см. раздел 5).

**Ошибки:**
- неправильный выбор в Task или Choice не означает «game over»;
- история идёт по другой ветке или персонаж переспрашивает («Wait, what? I said the *left* door»);
- через 2 ошибки подряд появляется мягкая подсказка.

## 4. Диалоги, перевод по тапу, три уровня текста

### Реплика
- Текст на английском печатается, есть кнопка 🔊 (озвучка браузером, только по нажатию).
- **Тап по слову** — перевод слова и пример. **Долгий тап или кнопка «RU»** — перевод всей фразы.
- Каждый тап запоминается: эти слова чаще возвращаются в повторении.

### Три уровня текста
Каждая важная реплика пишется в трёх вариантах. Сюжет и смысл одинаковые, отличается язык.

| | A1 (Easy) | A2 (Medium) | B1 (Hard) |
|---|---|---|---|
| Пример | «Go to room 3. Find the red box.» | «Go to room 3 and look for a red box. It's under the table.» | «Head over to room 3 — there should be a red box tucked under the table.» |
| Длина | до 8 слов | до 14 слов | без ограничений |
| Времена | Present, can | + Past, going to | + Present Perfect, условные |
| Лексика | базовая | + бытовые фразы | + фразовые глаголы, идиомы, сленг |

Неважные реплики (атмосфера, шутки) могут быть в одном варианте. Тогда автоматически используется самый простой подходящий уровень.

### Выбор реплики
- 2–3 варианта ответа. Для A1 они короткие и явно разные, для B1 различаются тоном и оттенком («Sure, whatever.» / «Of course, I'd love to.»).
- Тон влияет на отношения с персонажами (особенно в C).

## 5. Блокнот и повторение слов

### Блокнот
Общий для всех историй. В каждой истории он выглядит по-своему:
- **A** — «Frequency Log»;
- **B** — «Case Notes»;
- **C** — «Phone Notes».

Внутри у каждого слова или фразы:
- перевод и пример из сюжета, где он встретился (с картинкой сцены);
- откуда («Case Files, Ep. 3»);
- уровень освоения: ○ новое → ◔ знакомое → ◑ узнаю → ● освоено.

Фильтры: по историям, по темам, «сложные для меня».

### Скрытое повторение (как это работает)
У каждого слова есть **дата следующего повторения**:
- новое → через 1 день → 3 → 7 → 14 → 30;
- понял без перевода — интервал растёт;
- нажал перевод — интервал сбрасывается на 1 день.

Где слова «всплывают» в эпизоде:
1. **Recall-биты:** персонаж сюжета спрашивает или вспоминает слово.
2. **«Гибкие» реплики:** в эпизоде есть места с подстановкой. Пример: экран станции показывает «Warning: ___ low», в слот подставляется нужное слово из списка подходящих (fuel, power, water…).
3. **Предметы в Explore:** записки, вывески и сообщения собираются из шаблонов с нужными словами.
4. **Пересказ «Previously on…»** использует слова из прошлого эпизода.
5. **Daily Review на 1–2 минуты** — не тест, а мини-сцена истории («Jenna reads you the case notes — fill the gaps»). Необязательная, даёт +1 к серии, если эпизод уже пройден.

**Из другой истории:** если слово найдено в детективе, а пора повторить, оно может всплыть в гибкой реплике на станции, если подходит по теме.

## 6. Прогресс, серия, напоминания

**Ежедневный ритм:**
- каждый день открывается **1 новый эпизод в каждой истории** (догнать можно в любой момент);
- серия 🔥 засчитывается, если пройден один эпизод или Daily Review;
- **заморозка серии:** 1 бесплатная в неделю, чтобы пропуск дня не ломал мотивацию.

**Видимый прогресс:**
- «Понял без перевода»: график по неделям;
- освоенные слова и фразы: всего и по историям;
- прогресс сезонов.

**Напоминания от бота** (через сервер на GitHub Actions, раз в день вечером, не чаще):
- «🕵 Новое дело в Harbor City ждёт тебя»;
- «🔥 Серия 12 дней — 10 минут, и она не сгорит»;
- если 3 дня тишины: одно мягкое сообщение с клиффхэнгером, потом пауза на неделю.
- Можно отключить в настройках.

## 7. История A — Last Signal

**Жанр:** фантастика, выживание, тайна. Тревожно, но уютно.
**Завязка:** ты исследователь, который приходит в себя на полярной станции **Aurora-7**. Персонала нет, метель, связь есть только по старой рации.

**Персонажи:**
- **Maya Chen** — учёная с соседней станции, говорит быстро и по делу. Главный союзник.
- **Rook** — пилот, застрявший в разбитом самолёте в 20 км. Шутит, чтобы не паниковать.
- **Eli** — подросток, его голос иногда прерывается. Кто он и где — загадка.
- **ARIA** — бортовой ИИ станции. Говорит инструкциями, бывает «странной».
- **Голос без имени** — появляется в сезоне ночью на «пустой» частоте.

**Локации (набор 3D-деталей):** радиорубка, генераторная, кухня и столовая, жилые каюты, лаборатория, склад, шлюз и выход наружу, крыша с антенной. Общий набор: стены-панели, трубы, шкафы, экраны, лампы, снег за окном.

**Фирменная механика — «Do it by the instruction»:**
- инструкции на экранах и от ARIA: «Turn the valve clockwise, then press the green button»;
- навигация: ты ведёшь Rook по описанию местности («Walk past the broken tower and turn left at the frozen lake»);
- расшифровка: сообщения с помехами, где часть слов нужно восстановить по смыслу.

**Сезон 1 — «Aurora-7» (10 эпизодов):**
| # | Эпизод | Темы слов |
|---|---|---|
| 1 | Wake Up — первый сигнал по рации | приветствие, «where / who», помещения |
| 2 | Power — запустить генератор | инструкции, цвета, числа, направления |
| 3 | Food & Heat — кухня, запасы | еда, количество, «there is / are» |
| 4 | Rook's Crash — ведём пилота | направления, местность, погода |
| 5 | The Lab — записи пропавшего персонала | прошедшее время, профессии |
| 6 | Storm — шторм и отказ систем | срочность, предупреждения, «must / have to» |
| 7 | Eli — кто он? | чувства, вопросы, описание людей |
| 8 | The Night Frequency — чужой голос | догадки, «might / maybe», звуки |
| 9 | Trust — кому верить: Maya или ARIA? | мнения, согласие и несогласие |
| 10 | Signal Out — побег к антенне, клиффхэнгер сезона | планы, будущее время |

**Сезон 2 (набросок):** выход за пределы станции, соседняя станция Maya, корабль во льдах.

## 8. История B — Case Files: Harbor City

**Жанр:** уютный нуар, детектив.
**Завязка:** ты новый стажёр в маленьком агентстве **Blackwood & Reyes** в портовом городе Harbor City. Дела небольшие, но каждое оказывается связано с чем-то большим.

**Персонажи:**
- **Inspector Dana Reyes** — шефиня. Строгая, саркастичная, честная.
- **Oscar Blackwood** — второй партнёр, вечно «в отъезде». Подозрительно.
- **Jenna Park** — архивариус и хакер агентства, дружелюбная, говорит на сленге (материал для B1).
- **Officer Milo Grant** — полицейский, помогает, но не всё рассказывает.
- Подозреваемые и свидетели — новые в каждом деле.

**Локации (набор):** офис агентства (постоянная), кафе, порт и склад, квартира, отель, бар, рынок, музей, станция. Общий набор: стены и окна, мебель, неон, дождь, уличные фонари, контейнеры.

**Фирменная механика — «Catch the contradiction»:**
1. Улики собираются в досье: предметы, чеки, сообщения, фото.
2. На допросе свидетель говорит. Если кажется, что он врёт, можно нажать **«Objection!»** и выбрать улику из досье.
3. Попал — свидетель «ломается» и раскрывает новое. Промах — Reyes комментирует, без штрафа.
4. В финале дела — выбор виновного и цепочка улик.

**Как противоречия растут с уровнем:**
- **A1:** факты (цвет, время, место): «I have a blue car» против фото красной машины.
- **A2:** события и порядок: «I left before the rain» против мокрой куртки на фото.
- **B1:** грамматика и оттенки: «I'd never been there» против «I've been there before», косвенная речь, ирония.

**Сезон 1 — «The Harbor Mole» (8 дел по 2–3 эпизода, ~20 эпизодов):**
| # | Дело | Темы слов |
|---|---|---|
| 1 | The Missing Cat — разминочное дело | внешность, цвета, место |
| 2 | Coffee & Lies — кража выручки в кафе | еда, деньги, время, распорядок дня |
| 3 | Room 214 — пропажа в отеле | отель, вещи, прошедшее время |
| 4 | The Fake Painting — подделка в музее | искусство, описание, сравнения |
| 5 | Container 9 — контрабанда в порту | работа, транспорт, числа и коды |
| 6 | The Last Train — свидетель исчез | путешествия, расписание, планы |
| 7 | Market Day — шантаж на рынке | покупки, эмоции, вежливые просьбы |
| 8 | The Mole — кто сливает информацию из агентства | всё вместе, мнения, обвинения |

## 9. История C — Fresh Start

**Жанр:** жизнь и отношения + лёгкая тайна. Тепло, атмосферно.
**Завязка:** тебе 19, ты получил грант на учебный год в городке **Kinloch** на побережье Шотландии. Комната над кафе «The Gull», подработка, колледж. В комнате находится дневник прошлого жильца, Sam, который уехал внезапно, ничего не сказав.

**Персонажи:**
- **Fiona** — хозяйка кафе и комнаты. Добрая, говорит с шотландскими словечками (с переводом).
- **Kai** — сосед по этажу, музыкант, шутник. Первый друг.
- **Priya** — однокурсница, умная, амбициозная. Возможная симпатия или соперница.
- **Mr. Duncan** — смотритель маяка, ворчливый, знает больше, чем говорит.
- **Sam** — прошлый жилец. Только дневник, сообщения и слухи.

**Локации (набор):** комната героя, кафе The Gull, улица и набережная, колледж (аудитория, библиотека), паб (квиз-вечера), маяк, вокзал. Общий набор: дома, витрины, мебель, лодки, деревья. Времена года меняют свет и погоду.

**Фирменная механика — «Life choices»:**
- **ситуации:** снять комнату, принять заказ, собеседование, звонок в банк, поход к врачу. Практичный язык;
- **отношения:** у каждого персонажа есть шкала отношений. Тон ответов (вежливо, дружески, резко) её меняет. От отношений зависит, кто поможет с тайной Sam;
- **телефон героя:** чаты с персонажами (короткие сообщения, сленг, эмодзи), заметки и карта.

| 2 | The Room — заселение, правила, дневник Sam | дом, вещи, правила, «can / can't» |
| 3 | First Shift — смена в кафе | заказы, еда, вежливые фразы |
| 4 | College — первый день, Priya | учёба, расписание, хобби |
| 5 | Pub Quiz — вечер с Kai | развлечения, числа, факты |
| 6 | Bad Day — потерял кошелёк, звонок в банк | проблемы, просьбы, прошедшее время |

| 8 | Storm Night — шторм, вся улица в кафе | погода, эмоции, помощь |
| 9 | Sam's Message — неожиданное сообщение | догадки, «might / must have» |

## 10. Визуальный стиль и звук

**Общий стиль:** стилизованное low-poly 3D с мягким светом. Персонажи без детской «мультяшности», ближе к инди-играм (Firewatch, Kentucky Route Zero, A Short Hike, но взрослее). Камера — фиксированные красивые ракурсы, «диорамы», а не свободный бег.

| | Last Signal | Case Files | Fresh Start |
|---|---|---|---|
| Палитра | холодный синий, оранжевые лампы, северное сияние | ночь, неон, мокрый асфальт, тёплые окна | осень, тёплое золото, серое море, зелень |
| Свет | контраст тепла внутри и холода снаружи | ночное освещение, фонари | мягкий дневной, закаты |
| Музыка | эмбиент, синтезаторы, ветер | лоу-фай джаз, дождь | акустика, гитара, чайки |
| Интерфейс | «экран станции», моноширинный шрифт | «досье», печатная машинка | «телефон» и записки от руки |

**Персонажи в диалогах:** 3D-модель в сцене плюс 2D-портрет у реплики с 3–4 эмоциями.
**Звук:**
- генеративная музыка под каждую историю (как в текущем прототипе);
- озвучка браузером только по кнопке 🔊, автоматической озвучки нет.

## 11. Техническое устройство

**Основа:** то, что уже работает в прототипе — three.js без сборки, GitHub Pages, Telegram WebApp, облачное сохранение.

**Модули:**
| Модуль | Что делает |
|---|---|
| `engine/scene` | загрузка 3D-сцены истории, камеры-ракурсы, тап по объектам |
| `engine/episode` | проигрывание битов эпизода по данным |
| `engine/dialogue` | реплики, 3 уровня, перевод по тапу, выборы |
| `engine/vocab` | словарь, интервалы повторения, подстановка в слоты |
| `engine/profile` | уровень, серия, статистика, сохранение |
| `stories/a`, `stories/b`, `stories/c` | наборы 3D-деталей, персонажи, механика истории (инструкции, «Objection!», отношения) |
| `content/` | эпизоды в виде файлов данных (JSON) |
| `bot/` | GitHub Actions: раз в день читает, кто запускал бота, и шлёт напоминания |

**Эпизод — это файл данных**, а не код. Пример (сокращённо):
```json
{
  "id": "B-02-1", "story": "B", "title": "Coffee & Lies",
  "new": ["receipt", "till", "shift", "I was on my break"],
  "beats": [
    { "type": "recap" },
    { "type": "dialogue", "who": "reyes", "scene": "office",
      "text": { "a1": "We have a new case. Money is gone.",
                "a2": "We've got a new case — someone took money from a café.",
                "b1": "New case. Someone's been helping themselves to the till at The Gull." } },
    { "type": "explore", "scene": "cafe", "clues": ["receipt_2240", "apron", "cctv_note"] },
```

**Производительность:**
- сцены-диорамы: до ~150 объектов, общая геометрия, склеивание статики (уже есть в прототипе);

- целевая частота кадров — 60 на средних телефонах, автоснижение качества (уже есть).

**Напоминания:**
- GitHub Actions по расписанию раз в день;
- забирает новых пользователей через getUpdates и хранит их chat_id в закрытом хранилище;
- отправляет сообщения через Bot API.
- Токен бота — только в секретах GitHub, не в коде.
