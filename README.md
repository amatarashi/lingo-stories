# Lingo Stories — платформа (этап 7.1) и дело 1 Case Files целиком

Новая игра для изучения английского: сюжетные истории-«сериалы» для 16–21 лет, уровень A1–B1. Документы этапов лежат в [docs/](docs/). Старая игра Lingo Isles лежит отдельно, в `../lingo-isles`, и работает в боте как раньше.

## Дело 1 «Coffee & Lies» (2 эпизода)
Сценарий второй части: [docs/06-case1-part2.md](docs/06-case1-part2.md).
- **Часть 1, кафе ночью:** осмотр, допрос Тома, клиффхэнгер с зонтом Блэквуда.
- **Часть 2, развязка:**
  - «Previously on…»;
  - офис агентства: стол Блэквуда, отчёт кассы;
  - кафе ранним утром: допрос пекаря Daisy;
  - финальное обвинение: кто, когда и откуда мы знаем;
  - выбор «по правилам / дать шанс»;
  - штамп CASE CLOSED и звонок Блэквуда про «крота».
- Вторая часть открывается на следующий день после первой. Дженна в офисе спрашивает слова из первой части.

## Платформа (этап 7.1)
- **Первый запуск:** экран «Choose your story». Теста уровня нет: первые 6 реплик идут по нарастающей (2×A1, 2×A2, 2×B1), и уровень ставится по тому, где впервые понадобился перевод. Можно выбрать уровень вручную.
- **Главный экран:** три сериала-постера, серия 🔥, «сегодня 0/1 эпизода», сколько слов ждут повторения.
- **Экран сериала:** завязка, фирменная механика, персонажи, список эпизодов сезона. Статусы эпизодов: пройден / играть / завтра / сначала предыдущий / скоро.
  - Каждый день открывается один новый эпизод.
  - Готов пока только Case Files 1; остальные эпизоды появятся на этапах 7.2 и 7.4.
- **Блокнот:** общий для всех историй, с фильтрами «повторить», «сложные» и по сериалам.
- **Профиль:**
  - серия, рекорд и заморозка (1 пропуск в неделю прощается сам);
  - слова: встречено / знакомые / освоено;
  - график «понято без перевода» по неделям;
  - уровень, прогресс сериалов;
  - настройки голосов, музыки и напоминаний.
- **Сохранение:** localStorage плюс облако Telegram. Состояние делится на куски по 4000 символов, в облако уходят только изменившиеся куски, при запуске берётся более свежая копия.
- **3D-сцена** грузится только при входе в эпизод и ставится на паузу на главном экране.

## Графика, голоса, производительность
- **3D:** three.js r170 (в `vendor/`), toon-освещение в стиле стилизованного инди, без постобработки (виньетка и зерно сделаны в CSS, свечение — спрайтами).
- **Персонажи:** CC0-модели Quaternius (Ultimate Modular Men/Women) с анимациями из Universal Animation Library. Анимации переносятся на скелет моделей в `js/engine/retarget.js`.
- **Озвучка:** все реплики заранее записаны Kokoro TTS (локально, бесплатно) в `assets/voice/*.mp3`. Имя файла — хэш голоса и текста.
- **Музыка:** генерируется в WebAudio. Пока кто-то говорит, музыка и дождь приглушаются.
- **Телефон:** около 80 draw calls и 31k треугольников, адаптивное разрешение, на мобильных простые тени и 2 точечных света.

## Что проверяет прототип
Одна сцена, эпизод Case Files «Coffee & Lies» (часть 1), примерно 10 минут:
- **Диалоги в трёх уровнях.** Переключатель A1/A2/B1 вверху, текст меняется прямо на текущей реплике.
- **Перевод по тапу** на любом слове. Кнопка RU переводит всю фразу. Подчёркнутые слова отслеживаются и попадают в блокнот.
- **Осмотр сцены:** тап по «?» над предметами. На узком экране сцену можно свайпать.
- **Допрос с «OBJECTION!»:** поймать свидетеля на противоречии с уликой. Ошибка не наказывается, после двух ошибок подряд даётся подсказка.
- **Скрытое повторение:**
  - слова возвращаются через 1, 3, 7, 14, 30 и 60 дней;
  - если слово понято без перевода, интервал растёт; если открыт перевод, повтор снова через день;
  - на следующий день Дженна спрашивает слова прямо в сюжете.
- **Подстройка уровня:** если первые 6+ реплик понятны почти без перевода, игра предлагает сложнее; если перевод нужен часто — проще. В режиме «Не знаю» подстраивается сама.
- **Итог эпизода:** процент понятого без перевода, новые слова, серия дней, тизер.
- **Тест «следующего дня»:** кнопка в блокноте или на итоговом экране сдвигает время, чтобы сразу увидеть повторение.

## Запуск
Превью `lingo-stories` из `.claude/launch.json` (порт 5178) или любой статический сервер в этой папке.

Новый эпизод — это новый файл в `js/content/`.
- Сцены эпизода описаны в `scenes`: локация, настроение, кто в кадре. Персонаж, которого нет в текущей локации, говорит по телефону.
- Типы битов: `line`, `choice`, `explore`, `clue`, `interrogate`, `recall`, `recap`, `scene`, `accuse`, `stamp`, `end`, а для Last Signal ещё `task` (сделай по инструкции: тап по нужному предмету), `decode` (слово, потерянное в помехах: `{word}` в тексте) и `fx` (эффекты: `black`, `eyes`, `static`, `shake` и эффекты локации). Для Fresh Start — `chat` (переписка в телефоне героя, ответы могут менять отношения) и `rel: {персонаж: ±1}` у вариантов выбора; итог отношений показывается в конце главы.
- Голос персонажа может быть с фильтром: `voice: 'af_sarah+radio'` — генератор пропускает его через фильтр рации (`+aria` — голос компьютера).
- Новые эпизоды нужно добавить в `tools/voice-jobs.mjs` (озвучка) и `tools/check-lex.mjs`.

## Озвучка новых реплик
1. Составить список реплик: `node tools/voice-jobs.mjs > jobs.json`.
2. Записать новые реплики: `PYTHONIOENCODING=utf-8 python tools/make_voices.py jobs.json assets/voice`.
   - Нужны `kokoro-onnx`, `soundfile` (лучше в отдельном venv) и `ffmpeg`.
   - Уже записанные файлы пропускаются.

## Ассеты и лицензии
- `assets/models/` — сжатые модели (glTF-Transform + meshopt), около 2 МБ. `assets/src/` — исходники, их не нужно выкладывать.
- Персонажи, мебель и уличные модели — Quaternius (Ultimate Modular Men/Women, Ultimate House Interior, Modular Streets), анимации — Quaternius Universal Animation Library 1 и 2; всё CC0. Голоса сгенерированы моделью Kokoro-82M (Apache 2.0). Движок three.js и meshoptimizer — MIT. Шрифты — Google Fonts (OFL / Apache 2.0).
- Полный список с источниками и текстами лицензий — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Добавляя сторонний ассет, сразу дописывай его туда.
- `tools/viewer.html` и `tools/anim.html` — страницы для проверки моделей и анимаций.
